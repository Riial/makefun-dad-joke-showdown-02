# Dad Joke Showdown — v2

One dad joke, written to `/output/entry.txt` by `main.py` (Python 3.13, stdlib only):

> I asked my dog what's two minus two. He said nothing.

Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun. The program validates the joke is 1–200 characters of UTF-8 text and not only whitespace, then writes it out. Run it with `python3 main.py`.
